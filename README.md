# GeometryWalk

Copy of the game [Geometry Dash](https://www.geometrydash.com/) made as a school project.
Game made with Unity version 6000.3.9f1. The game has soley been tested on Windows 10. Should work on Linux. 

## Download
Download build for respective compatible OS. Extract downloaded folder into appropriate place. Run "GeometryWalk.exe"
if on Windows or "GeometeyWalk.x86_64" on Linux. 

## Known bugs

If players press jump at the right time when the player is travelling on foot, the player will be sent high into the sky.
